MacNotch turns the notch on your MacBook into a Dynamic Island.

**Install:** download `MacNotch.dmg` below, open it, and drag MacNotch into Applications. The README has the full step-by-step guide, including how to open it the first time.

**New in 1.1**
- Choose what sits beside the notch: weather, battery, time, date or shelf count, or nothing
- Edit mode right in the island: everything wiggles like iPhone's home screen; drag to rearrange widgets and web page icons, tap minus to remove, Add Widget to bring one back
- Drag a link from your browser onto the notch to save it as a web page
- Web page icons show only the logo, with no tile behind them
- Built with Xcode 27, so macOS 27 shows the new iOS 27 generation of Liquid Glass, with darker edges and brighter highlights on the island
- Apple's system colors throughout and an SF Symbol menu bar icon

**Everything from 1.0**
- Live Activities beside the notch: Apple Music with artwork and sound bars, charging and low battery alerts
- Hover to open a Liquid Glass island with Now Playing, Weather, Web Pages and a File Shelf
- Classic Black style and a Clear-to-Tinted glass slider
